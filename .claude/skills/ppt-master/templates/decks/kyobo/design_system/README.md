## 콘텐츠 원칙

- 모든 문서는 **한국어**로 작성합니다. 제목·소제목은 명사형으로 짧게 끝맺고, 본문 항목은 개조식(예: `세부과제`, `핵심내용`)으로 씁니다.
- 슬라이드 제목은 `1. 테스트`처럼 **번호 + 마침표 + 공백 + 제목**으로 씁니다. 표지는 번호 없이 제목, 날짜(`2026. 10`), 팀명만 둡니다.
- 핵심 메시지는 슬라이드 상단에 `“ 핵심내용 ”`처럼 따옴표로 감싼 한 줄로 요약합니다.
- 목록 기호는 `○`(주 항목), `-`(하위 항목), `▪`(타일 옆 불릿)만 씁니다. 이모지는 쓰지 않습니다.
- 기간은 `[Phase 1] 2000~2000` 형식, 부연 설명은 괄호 `( 부연설명 )`로 씁니다.

## 시각 원칙

**색.** 바탕은 `surface`(흰색), 본문은 `ink`, 보조 텍스트는 `ink-muted`. 브랜드 색은 `navy`(기본)와 `green`(보조) 두 가지이며, 제목 아래 라인은 좌측 1/6 `green` + 나머지 `navy`로 고정합니다. `green`, `orange`, `coral`은 면·선·장식에만 쓰고 텍스트 색으로 쓰지 않습니다(흰 바탕 대비 부족). 강조할 단계·항목은 `navy` 면에 `on-navy` 글자를 씁니다. 중립 면은 `gray-100`(라벨 타일), `gray-200`(번호 칸), `gray-300`(비활성 칩·점선).

**글꼴.** 본문은 나눔고딕(`sans`), 제목은 같은 계열의 ExtraBold(800). 번호·영문 로고성 텍스트는 `latin` 계열(Century Gothic)을 씁니다. 서열은 글꼴 교체가 아니라 굵기와 크기로 만듭니다: 표지 `cover-title` → 제목 `section-title` → 핵심 `key-message` → `subhead` → `body-lg` → `body` → `caption`. 글꼴 파일은 포함돼 있지 않으므로 PPT를 공유할 때 받는 쪽 PC에 나눔고딕이 설치돼 있어야 합니다.

**선과 면.** 박스는 직각(`radius-none`)이 기본이고 둥근 사각형은 `radius-sm`만 씁니다. 그림자는 쓰지 않습니다(깔때기 그라데이션 제외). 점선(dotted)은 일반 박스, 파선(dashed)은 활성·결론 박스에 씁니다. 선 굵기는 `stroke-*` 토큰을 따릅니다.

**배경 모티프.** 표지는 녹색에서 네이비로 이어지는 큰 곡선(웨이브)이 하단을 가로지릅니다. 본문 슬라이드는 장식 없이 제목 라인과 로고만 둡니다. 곡선은 새로 그리지 말고 원본 마스터의 배경 이미지를 그대로 사용합니다.

**레이아웃.** 슬라이드는 `slide-width` × `slide-height`(1096×720px). 가장자리 여백은 `space-8`, 박스 사이는 `space-6`, 박스 안쪽은 `space-4`. 구성은 제목 → 핵심 메시지 → 단계 칩 → 세부과제 박스, 또는 제목 → 소제목 → 비교 카드 → 결론 박스 순서입니다.

## 아이콘과 로고

별도 아이콘 세트는 없고 ○, -, ▪ 같은 문자 기호만 씁니다. 로고는 `assets/Logos/kyobo-logo.png`(KYOBO 워드마크 + 새싹)를 복사해서 쓰며 다시 그리지 않습니다. 원본 해상도가 낮아(163×82) 큰 크기로 키우지 말고 슬라이드 우측 상단 36px 높이 안팎으로만 사용합니다. 표지 하단의 로고·슬로건은 마스터 배경 이미지에 포함돼 있습니다.

## 컴포넌트

- `TitleBar`: 번호 제목 + 로고 + 녹/남 라인
- `KeyMessage`: “ 핵심내용 ” 한 줄 요약
- `PhaseChevron`: 단계 라벨 + 화살표 칩(활성/비활성)
- `TaskBox`: 점선 박스 + ○ 세부과제
- `LabelTile`: 회색 라벨 타일 + ▪ 목록
- `NumberedCard`: 제목 + 번호 칸 목록 카드
- `ConclusionBox`: 깔때기 + 점선 결론 박스

## 확장 디자인 가이드 (v2)

색 톤(네이비·그린)과 제목 라인·로고·직각 박스 기본은 유지하고, 형태만 넓힙니다.

- **틴트**: `navy-50 #E6EEF7`(강조 카드), `navy-100 #CBD9EA`(이미지 자리·큰 인용부호), `navy-300 #8FAFD4`, `navy-500 #4D7FB5`(계층·막대), `green-50 #EAF6E9`(보조 카드). 텍스트는 네이비·검정만.
- **형태**: 카드 `rx=6`, 번호 원(네이비 원 + 흰 숫자), 카드 상단 8px 바(그린/네이비), 네이비 원 위 흰색 `tabler-outline` 아이콘, 전면 이미지는 `#002060` 스크림 0.5.
- **새 페이지 11종**: 이미지 분할 · 특징 카드 · 대표 지표 · 번호 프로세스 · 2×2 매트릭스 · 인용 · 계층 · 허브 · 갤러리 · 대안 비교 · 전면 이미지. 선택 기준은 `templates/design_spec.md` §VII.
- **크기(발표용)**: 제목 32~40 / 핵심 메시지 32 / 라벨·본문 24 / 설명 18 / 대표 지표 56~140. 보고서용 16~18은 인쇄·검토용.
- **물리 크기**: 29.016 × 19.05 cm(10445750 × 6858000 EMU)로 고정되며, 내보내기에서 자동 적용됩니다.
